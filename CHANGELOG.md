# Changelog

## 1.0.0 - release candidate

Initial public-release implementation target.

- Added region-aware vector and bathymetry build pipeline.
- Added local, regional, western-Pacific and antimeridian-spanning Pacific configurations.
- Added public source registry and provider-respecting acquisition workflow.
- Added maritime-boundary status and source metadata schemas.
- Added QGIS styles, PyQGIS project generation and publication layout automation.
- Added QGIS-native antimeridian line splitting utility.
- Added SHA-256 provenance manifests and verification.
- Added Python and QGIS continuous-integration workflows.
- Added citation policy, contributor guidance and software metapaper draft.
- Added a loopback-only `mgrb ui` product interface over the canonical build engine.
- Added area/background/maritime-layer selection and custom-extent GIS defaults.
- Added generic CSV/TSV, GeoJSON, GeoPackage and Shapefile schema inspection.
- Added explicit schema confirmation, compact QC and provider-segment-aware track generation.
- Added a neutral portable QGIS product layer tree and reproducible selection-state manifests.
- Added a documented computed median/equidistance reference capability whose legal status is
  always `COMPUTED_REFERENCE`.
- Added a redistributable PANGAEA Xue Long public demo with 3,186 true-track positions.
- Added deterministic portable package ZIPs, journal-width previews and release-security audit.
