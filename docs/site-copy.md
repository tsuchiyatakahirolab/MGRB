## Maritime Geospatial Research Base (MGRB)

MGRB is an open-source, reproducible geospatial base for maritime research. It integrates public bathymetry, coastline and maritime-zone reference data into reusable QGIS projects, with standardized projection handling, antimeridian processing, cartographic styles, provenance and versioned citation metadata.

The project is designed for researchers who need a documented geographic base on which to conduct their own maritime analysis. Source code, documentation, releases and citation information are maintained on GitHub.
