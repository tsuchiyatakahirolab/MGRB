# Data-source policy

MGRB is an integration layer, not a mirror of upstream data portals.

Preferred sources are primary providers and public authorities. The source registry records the upstream version/date, DOI or citation, licence, retrieval method, and redistribution constraints.

Core v1.0 sources:

- GEBCO_2026 for global bathymetry and terrain.
- Natural Earth for publication-scale physical base layers.
- GSHHG for higher-resolution global shoreline work where appropriate.
- Marine Regions for a widely used global maritime-zone reference layer, ingested as a reference dataset rather than a legal authority.
- Government or treaty sources for legally significant boundary claims and delimitations when those are needed for a study.
