# Governance

MGRB uses maintainer review for changes to source policy, metadata schemas, supported coordinate conventions, release provenance, licensing and canonical cartographic styles. Community contributions may extend source adapters, documentation and tests through pull requests. Tagged releases represent canonical versions and are not rewritten after publication.

The maintainer may reject changes that weaken source traceability, blur the distinction between canonical and derived data, introduce non-public material, or create misleading legal certainty in maritime-zone representation.
