# Contributing

Contributions that improve public geospatial reproducibility, source documentation, QGIS compatibility, cartographic consistency, metadata, tests or accessibility are welcome.

Before opening a pull request, read `AGENTS.md` and run the required checks. Contributions must be reproducible from public inputs and must not contain licensed or non-public analytical datasets or derived findings from them. New source integrations must document provider, version/date, acquisition route, licence or terms, redistribution status and recommended citation.

Changes to maritime-zone reference data must preserve source and status metadata. A geometry should not be represented as legally authoritative solely because it appears in a general-purpose boundary provider.
